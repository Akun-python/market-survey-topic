## 🎯 选题内容规范

每个选题档案（`选题说明.docx`）包含五要素：

| 要素 | 说明 |
|---|---|
| **研究对象** | 谁（人群/主体） |
| **核心变量** | 研究什么（动机/意愿/满意度/行为） |
| **研究阶段** | 早期 / 中期 / 长期 |
| **可行性** | 数据渠道与调研路径 |
| **参考来源** | ✅ 官方/权威媒体（可直接引用）｜🔶 行业报告/媒体线索（使用前须下载原文核验） |

> 📌 证据分级：**✅** = 官方政策/权威媒体，可直接引用；**🔶** = 行业报告/媒体线索，参赛前必须下载原文核对，保证数据真实可溯、不虚构。

## 🔄 更新机制（核心）

> 本选题库**持续追踪最新信息**，随政策、市场与热点变化**定期更新**：

1. **🌐 持续追踪最新信息** — 每轮选题研发联网检索最新政策文件、权威媒体与行业报告（国家统计局、商务部、发改委、文旅部、教育部等官方来源 + 权威行业白皮书），保证选题锚点使用最新数据。
2. **➕ 持续补充新选题** — 新热点出现即新增选题。2026 年已新增：仅退款新政、演出强实名、AI 编程助手、棉花娃娃（娃圈经济）、以竹代塑、官方认证二手机、银发邮轮、匹克球、自助洗车、温泉康养等。
3. **🧹 定期清理与替换** — 对过气热点、老套题材、库内重复选题，一律删除或替换为更新切口，保持全库 520 题"无重复、无过气"。
4. **🔖 证据分级标注** — 每题参考来源标注 ✅ / 🔶，数据可追溯、不虚构。
5. **📝 版本留痕** — 所有更新通过 git 提交留痕，README 同步记录变更日志。
