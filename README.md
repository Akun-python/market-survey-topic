## 📌 选题库是什么

本库是面向 **正大杯（全国大学生市场调查与分析大赛）** 的 **500 个选题合集**，按主要行业/应用场景归入 **21 个行业子目录**。

每个选题目录内含三份文件：
- `选题说明.docx` — 选题档案（研究对象 / 核心变量 / 研究阶段 / 可行性 / 参考来源）
- `选题说明.pdf` — PDF 版
- `选题说明_水印版.pdf` — 加水印 PDF（正大杯全程指导：a237658765）

每个行业子目录内还有独立的 `README.md` 选题清单。

## 🔄 更新机制（重要）

> 本选题库会**持续追踪最新信息**，随政策、市场与热点变化**定期更新**：

1. **跟踪最新政策与热点**：每轮选题研发都会联网检索最新政策文件、权威媒体与行业报告（国家统计局、商务部、发改委、文旅部、教育部等官方来源，以及权威行业白皮书），保证选题锚点是最新数据。
2. **持续补充新选题**：新热点出现即新增选题（如 2026 年新增：仅退款新政、演出强实名、AI 编程助手、棉花娃娃娃圈、以竹代塑、官方认证二手机、银发邮轮、匹克球等）。
3. **定期清理与替换**：对过气热点、老套题材、与库内重复的选题，会**删除或替换**为更新的切口，保持全库 500 个选题"无重复、无过气"。
4. **证据分级标注**：每题参考来源标注 ✅（官方/权威媒体，可直接引用）与 🔶（行业报告/媒体线索，使用前需下载原文核验），保证数据可追溯、不虚构。
5. **版本与提交记录**：所有更新通过 git 提交留痕（见 `git log`），每次更新会写明变更内容。
