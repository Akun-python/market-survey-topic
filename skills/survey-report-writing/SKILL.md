# SK6 报告撰写与润色：把全流程素材装配成参赛报告（当届页数上限内）

> **一句话**：报告文本 15 分考的是「**逻辑清晰、格式规范、文本精炼、图文生动、可读性强**」——同样是数据，会写的人能多拿 10 分。

## 一、定位与适用场景

- **用在报告哪里**：全文（标题页、摘要页、目录页、正文、参考文献、附录）。
- **用在什么阶段**：分析基本完成后开始搭骨架；摘要（SK7）与结论（SK8）可在本 skill 中并行完成。
- **不适用**：素材还没齐（至少要有：背景、方案、数据结果、图表清单）。

## 二、输入清单

| 输入 | 来源 |
|---|---|
| 背景分析稿 | SK1 产出（第一章素材） |
| 方案与抽样稿 | SK2 产出 |
| 问卷与信效度 | SK3 产出（附录素材） |
| 分析结果与图表 | SK4/SK5 产出（结论—证据链表 + 图表文件） |
| 评分表与评审说明 | `references/竞赛方式计分及报告评审说明.md` |

## 三、标准步骤

### 第 1 步｜搭九章骨架 + 页数预算

先写目录、再填内容。正文上限以当届要求为准（当前赛制 ≤65 页），建议预算：

| 部分 | 内容 | 页数 |
|---|---|---|
| 封面 + 摘要 + 目录 | — | 4（摘要 1600–2000 字约 2 页） |
| 1 绪论 | 背景/意义/目的/创新点 | 4–5 |
| 2 文献综述与理论基础 | 综述 + 理论模型 | 3–4 |
| 3 研究设计 | 框架/假设/抽样/问卷设计 | 5–6 |
| 4 调查实施与质量控制 | 组织/进度/前中后质控/信效度 | 3–4 |
| 5 样本描述与现状分析 | 描述统计 + 差异性检验 | 4–5 |
| 6 影响因素建模（核心） | 聚类/画像 + SEM/Logit/Probit | 6–8 |
| 7 专项分析（可选） | 文本/舆情/预测 | 3–4 |
| 8 结论与建议 | SK8 产出 | 3–4 |
| 参考文献 | GB/T 7714 | 1–2 |
| 合计（不含附录） | | **≈ 35–45**（实际约 40；上限以当届 ≤65 页为准） |
| 附录 | 问卷、代码、访谈、照片 | 不计正文 |

### 第 2 步｜写正文（四原则）

1. **数据先行**：段落先给发现/数字，再解释"为什么重要"；
2. **问题导向**：每章开头 1 句"本章回答什么问题"，章尾 3–5 条小结；
3. **图表代言**：能用图说清的不用大段文字；图表先引后现；
4. **一段一个观点**：段落 3–5 行；小标题用动宾结构（"信任程度通过感知易用性间接影响参保意愿"）。

### 第 3 步｜对齐逻辑链（防"各章各说各话"）

做一张 **研究闭环映射表**（可放附录或自检用）：

| 研究问题 | 假设 | 变量/题项 | 分析方法 | 结论编号 | 对应章节 |
|---|---|---|---|---|---|
| 研究点 1 认知 | H1 | Q9–Q13 | 列联/卡方 | 结论 1 | 5.2 |
| 研究点 2 意愿 | H2–H4 | Q17–Q27 | SEM | 结论 2–4 | 6 |

任何一环断了（有问题无变量、有变量无方法、有方法无结论），写作时补或删。

### 第 4 步｜统一格式（评委第一眼印象）

- **标题层级**：一级 `一、`/`## 1`，二级 `（一）`/`### 1.1`，三级 `1.`——全报告统一，不混用；
- **图表**：图题下、表题上；三线表（顶线、表头线、底线）；编号全文连续；图目/表目与正文一致；
- **参考文献**：GB/T 7714 格式，正文上标引用 `[1]` 与文末一一对应；
- **数字**：阿拉伯数字、单位统一（% 与百分点区分）、千分位一致；
- **缩写**：首次出现给全称（如 SEM（结构方程模型））。

### 第 5 步｜三轮润色（结构 → 句子 → 格式）

**第一轮（结构）**：
- 目录能否只看标题就复述研究逻辑？
- 每章是否有"本章回答→分析→小结"？
- 结论是否回应了引言提出的每个问题？

**第二轮（句子）**：
- 删口语/主观词（"我们认为""众所周知""非常"）；
- 长句拆短；被动语态适度；
- 删重复表述；每段有主题句。

**第三轮（格式）**：
- 错别字（含图表内文字）；
- 编号连续性（图 1…图 N、表 1…表 N、公式 (1)…）；
- 页码、页眉、目录自动更新；
- 超页检查（≤65 页，超页系统拒收）。

### 第 6 步｜提交前总检（对照评审说明逐条过）

| 评分项 | 自检问题 | 通过标准 |
|---|---|---|
| 研究选题 10 | 选题新颖、有实际价值？ | 背景里有"缺口"与"痛点" |
| 文献研究 7 | 文献是否在研究中实际用到？ | 方法/量表/假设能追溯到文献 |
| 方案设计 20 | 完整性/科学性/可行性？ | SK2 清单全过 |
| 调查实施 20 | 组织/数据/质控有效？ | SK2/SK3 清单全过，附录有原始数据与照片 |
| 分析与结论 25 | 方法合理、结论有支撑、建议可操作？ | 结论—证据链表完整；SK8 清单全过 |
| 报告文本 15 | 逻辑/格式/精炼/图文/可读？ | 三轮润色完成、无超页 |
| 研究创新 3 | 亮点是否突出？ | 创新点 3–4 条均在正文有对应 |

## 四、产出模板

```markdown
# 〔报告标题：主标题 + 副标题（研究对象/方法/地区）〕
# 摘要（1 页）
# 目录（自动生成）
## 一、绪论
## 二、文献综述与理论基础
## 三、研究设计
## 四、调查实施与质量控制
## 五、样本描述与现状分析
## 六、〔核心研究〕影响因素分析
## 七、〔专项分析：文本/预测/画像〕
## 八、结论与建议
## 参考文献
## 附录 A 调查问卷 / B 数据分析代码 / C 访谈记录 / D 调查照片
```

## 五、验收标准（逐条打勾）

- [ ] 目录与正文标题一一对应，无"孤儿章节"
- [ ] 正文不超当届上限（当前 ≤65 页）；摘要 1 页；每章有小结
- [ ] 研究闭环映射表无断环（问题→假设→变量→方法→结论）
- [ ] 图表编号连续、图目/表目与正文一致、每图有来源注
- [ ] 参考文献 GB/T 7714 且正文引用一一对应
- [ ] 术语/缩写在首现处定义，全文统一
- [ ] 无口语化、无"我们认为"类主观表述
- [ ] 附录含问卷全文、代码脚本、访谈记录
- [ ] 正文与附录分开提交（按赛制要求）

## 六、常见坑

1. **超页**：正文 70+ 页被系统拒收 → 先做页数预算再写。
2. **摘要页信息量不足/超长**：见 SK7。
3. **图表无来源、编号跳号**。
4. **结论与建议断层**：结论说 A 影响 B，建议却谈 C。
5. **文献只在综述出现一次**：正文分析/量表处从不引用 → "文献研究"扣分。
6. **各章口径不一**：样本量在摘要 1673、正文 1680。
7. **套话痕迹重**：大段定型排比、无具体数字 → 评审敏感。
8. **格式混搭**：`一、` 与 `1.1` 混用、图表样式不统一。

## 七、开源工具链（完整命令见 `OPEN_SOURCE_STACK.md`）

- **Markdown → PDF/Word**：`pandoc` + xelatex（中文用 xeCJK），或 `quarto`（统一模板、自动目录、代码块）；`typst` 可作轻量排版备选；
- **docx 直出**：`python-docx` 套模板（封面/三线表/标题样式）；LibreOffice 命令行批量转 PDF；
- **版本管理**：`git` 每章一提交，便于回滚与评审留痕；
- **引用**：Zotero + Better BibTeX（GB/T 7714 csl）；
- **校验**：脚本/grep 检查图表编号连续、页数超限、数字口径一致（如摘要 vs 正文的样本量）。

## 八、写法要点（对照历届获奖作品自检）

高分作品的整体结构通常具备以下特征：

1. 目录可复述研究逻辑：背景 → 方案 → 实施 → 分析 → 结论 → 建议，逐层递进；
2. 每章有"本章回答什么问题 + 章尾 3–5 条小结"，无孤儿章节；
3. 结构可按选题调整：六章紧凑型（方案→实施→数据→分析→结论）、九章递进型、或"产品-消费者-行业"多维型；
4. 附录成体系：问卷、代码、访谈记录、原始数据说明分节编号（如附录 A–H）；
5. 图表与正文一一对应，图目/表目与内容严格一致；
6. 研究闭环映射表（问题→假设→变量→数据→方法→结论）无断环。
