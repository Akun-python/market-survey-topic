# SK7 摘要撰写：用 1600–2000 字让评委抓住全部亮点

> **一句话**：摘要不是"目录的文字版"，而是「**背景 1 句 → 对象 1 句 → 方法（带数字）3 句 → 结果（带数字）4 句 → 价值 1 句**」的压缩包，评委只凭它就决定第一印象。

## 一、定位与适用场景

- **用在报告哪里**：摘要页（独立页，常用 2 页，按当届格式），位于标题页之后、目录之前；可另附英文摘要。
- **用在什么阶段**：**结论写完、报告定稿前**写（先 SK8 后 SK7，确保摘要概括的是最终结论）。
- **不适用**：报告未定稿时不要写摘要（数字一变全篇报废）。

## 二、输入清单

| 输入 | 来源 |
|---|---|
| 全文定稿或定稿级素材 | SK6 完成稿 |
| 结论与建议终稿 | SK8 产出 |
| 关键数字 | 样本量/有效率/核心系数/p 值/占比（从正文表格抄录，禁止估改） |
| 关键词候选 | 研究对象、核心变量、方法（各 1–2 个） |

## 三、五要素结构（照表填空即可）

| 要素 | 句数 | 必含内容 | 示例写法 |
|---|---|---|---|
| ① 背景 | 1–2 | 政策/现象 + 痛点（不展开） | "政策目标/行业乱象/受灾+补贴试点"式矛盾开头 |
| ② 目的与对象 | 1 | 研究谁、在哪、做什么 | "以〔某市/某群体〕为对象，围绕〔研究点 1〕与〔研究点 2〕" |
| ③ 方法与样本 | 2–4 | 抽样方法 + 样本量 + 有效率 + 核心方法名（≥2 个） | "发放〔N〕份、有效〔n〕份（有效率〔x%〕），综合运用〔A、B、C〕" |
| ④ 结果 | 3–5 | 每个研究点 ≥1 条结论，每条带数字或方向 | "〔变量〕显著影响〔意愿〕（β=…，p<0.05）" |
| ⑤ 价值/建议 | 1–2 | 分主体建议或理论/实践价值 | "据此为〔主体 1/2/3〕提出〔建议方向〕" |

**字数分配**（目标 **1600–2000 字**）：背景 ≤15%（240–300 字）/ 对象 10%（160–200）/ 方法 30%（480–600）/ 结果 35%（560–700）/ 价值 10%（160–200）。

## 四、摘要结构自查（三种常见组织方式）

| 维度 | 常见写法 1（按研究链） | 常见写法 2（编号结论） | 常见写法 3（模型主线） |
|---|---|---|---|
| 篇幅 | 1600–2000 字 | 1600–2000 字 | 1600–2000 字 |
| 背景写法 | 政策 → 行业矛盾 | 现象 → 新场景 → 人群 | 政策/灾害 → 试点 → 需求缺口 |
| 结果写法 | 按研究链分点（认知/意愿/支付/前景） | 编号结论 5–7 条，每条带数字 | 围绕自建模型的分层结构 |
| 建议写法 | 分主体（政府/企业/社区/个人） | 策略主题 5–8 条 | 阶段化或双层建议 |

**共性**：① 必给样本量与有效率；② 方法名准确（SEM、有序 Probit、K-prototype、中介效应）；③ 结论均带数字或方向；④ 建议落主体或落动作。

## 五、写作模板（中文）

> 〔背景 1–2 句：政策/现象 + 痛点〕。本文以〔对象 + 地区〕为研究对象，围绕〔研究点 1〕与〔研究点 2〕展开。采用〔抽样方法〕获取〔发放量〕份问卷、有效〔n〕份（有效率〔x%〕），并综合运用〔方法 A、方法 B、方法 C〕。研究发现：（1）〔结论 1，带数字/方向〕；（2）〔结论 2〕；（3）〔结论 3〕。据此，本文为〔主体 1/2/3〕提出〔建议方向〕，以〔价值句〕。

**关键词**：3–5 个（最多 6），= 对象 + 核心变量 + 方法组合，例：「新能源汽车；使用意愿；感知易用性；结构方程模型」。

**英文摘要**（如需）：同结构，术语与正文一致，篇幅约为中文的 1/3（中文 1800 字 ≈ 550–600 words）；先由团队定稿**术语中英对照表**（对象/方法/核心变量），再逐句对照写，避免机翻痕迹；数字保留，无"meaningful/significant"类空修饰。

## 六、验收标准（逐条打勾）

- [ ] 中文摘要 1600–2000 字；英文 ≤600 words（如提供）
- [ ] 必备数字 ≥4 个：样本量、有效率、≥1 个系数/占比、p 值或显著性
- [ ] 抽样方法与样本量写清（阶段/方法 + n）
- [ ] 每个研究点至少 1 条结果，且与正文结论一致
- [ ] 方法名准确（SEM ≠ 回归；CVM 与有序 Probit 搭配；K-prototype ≠ K-means）
- [ ] 标题中的关键词均在摘要出现
- [ ] 无"取得良好效果""意义重大"类空话
- [ ] 关键词 3–5 个，不与标题逐字重复
- [ ] 摘要独立成页（常用 2 页），与正文页码/目录一致

## 七、常见坑

1. **背景占一半**：2000 字里 1000 字讲政策 → 评委看不到研究做了什么；正常应控制在 300 字以内。
2. **无样本量/有效率**：抽样章节拿不到分，摘要也失分。
3. **方法罗列无因果**："用了 A、B、C、D" 而不说分别解决什么问题 → 堆砌感。
4. **结论无数字**："消费者接受度较高" → 给"平均得分 3.4/5、68.2% 选择愿意"。
5. **摘要与正文数字打架**：样本 1673 写成 1680 → 全文可信度崩塌。
6. **关键词随意**：写"调查/研究/分析"等无信息词。
7. **英文摘要机翻**：一眼露怯，宁可精写不求全。

## 八、开源工具链（完整命令见 `OPEN_SOURCE_STACK.md`）

- **字数统计**：Python 一句话脚本（中文字符计数）或命令行 `wc`；
- **关键词候选**：`jieba.analyse.extract_tags`（TF-IDF / TextRank）生成候选，**人工定稿** 3–5 个；
- **数字一致性检查**：脚本从正文表格提取样本量/有效率/核心系数，与摘要逐项比对（防"1673/1680"类错误）；
- **英文润色**：LanguageTool（开源本地版）改基础语法，术语一致性由团队核对。

## 九、写法要点（对照历届获奖作品自检）

高分作品的摘要页通常具备以下特征：

1. 五要素齐全，方法与结果占 65% 以上篇幅；
2. 数字密度高（样本量、有效率、系数、p 值 ≥4 个）；
3. 方法名准确且有用途说明（不是罗列）；
4. 每条结果回应一个研究点，与正文结论逐条对应；
5. 建议落主体或落动作（分层/策略/阶段化三选一）；
6. 关键词 3–5 个 = 对象 + 核心变量 + 方法，不与标题重复。
