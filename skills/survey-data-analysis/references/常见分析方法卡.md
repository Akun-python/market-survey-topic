# 常见市场调查分析方法卡

> 本卡是方法选择与复核清单，不是“方法越多越好”。所有方法先匹配研究问题、变量测量水平、抽样设计和样本量；结果须报告效应量、不确定性、假设与局限。实现主要依赖 MIT/BSD/Apache 等开源 Python/R 生态，许可证以各依赖的发行版与仓库为准。

## 1. 描述与数据质量

| 问题 | 推荐方法 | 最少报告 |
|---|---|---|
| 类别/多选题分布 | 频数、比例、Wilson 区间 | n、分母、多选规则、缺失 |
| 连续变量 | 均值SD、中位数IQR、分位数、直方图/箱线图 | n、均值/中位数、离散度、异常处理 |
| 两个连续变量 | Pearson（近似线性）或 Spearman（等级/非正态） | r、95%CI、p、散点图、不能写因果 |
| 重复测量一致性 | ICC、Bland–Altman | ICC类型、差值偏倚、区间 |
| 分类一致性 | Cohen/Fleiss κ | κ、类别分布、置信区间 |

## 2. 差异与推断

- 两独立组均值：Welch t 检验；配对前后：配对 t；不满足近似条件：Mann–Whitney U / Wilcoxon。
- 三组及以上：Welch ANOVA + Games–Howell；近似正态且方差齐时 ANOVA + Tukey；非参数用 Kruskal–Wallis + Dunn（多重比较校正）。
- 分类变量：Pearson χ²；小期望频数用 Fisher 精确检验或合并类别；报告 Cramér’s V。
- 有序等级：趋势检验、Spearman 或有序回归；不能把 Likert 单题默认当连续正态。
- 多重检验：预先区分主要/次要结果；探索性一组检验用 Benjamini–Hochberg FDR 或明确未校正。

## 3. 回归与解释模型

| 结果变量 | 模型 | 诊断重点 |
|---|---|---|
| 连续 | OLS / WLS / 稳健回归 | 残差、异方差、共线性、影响点、稳健SE |
| 二分类 | Logistic / Penalized Logistic | 线性预测子、分离、校准、AUC仅作区分度 |
| 无序多分类 | Multinomial Logistic | 基准类别、IIA假设/替代模型、边际效应 |
| 有序等级 | Ordered Logit/Probit | 比例优势假设、边际效应、类别稀疏 |
| 计数 | Poisson / Negative Binomial | 过度离散、零膨胀、暴露量offset |
| 选择/购买金额 | 两部模型、Tobit（需理论依据）或分位数回归 | 结构性零值、截尾/删失，别机械套用 |
| 面板/分层 | Mixed Effects / GEE | 聚类单位、相关结构、随机效应假设 |
| 生存/留存 | Kaplan–Meier、Cox | 删失、比例风险、时间起点、事件定义 |

解释模型：先画DAG或写识别假设；控制变量不能仅因p值筛选。回归结果报告系数/OR、95%CI、基准类别、N、缺失与权重；预测任务另报告交叉验证和校准，不能用训练集R²当泛化能力。

## 4. 潜变量、量表和结构方程模型（SEM）

### 4.1 正大杯常用 SEM 工作流

1. **理论模型**：依据文献和研究框架写出潜变量、观测题项、路径方向、控制变量和可证伪假设；先画路径图/DAG，不能先跑模型再倒推理论。
2. **测量模型（CFA）**：每个反映性潜变量通常至少3个题项；报告标准化载荷、载荷显著性、复合信度 CR、AVE、区分效度（如 HTMT/Fornell–Larcker）和题项删除理由。形成性构念不能套用 α/AVE 的反映性规则。
3. **结构模型**：报告标准化路径系数 β、SE、p、95%CI、R²、必要时 f²/Q² 或预测误差；同时报告样本量、缺失/权重、估计器和软件版本。
4. **拟合与诊断**：报告 χ²、df、χ²/df、CFI、TLI、RMSEA及CI、SRMR；指标只是整体拟合参考，不能用单一阈值宣布理论正确。检查残差、Heywood问题、负方差、标准误、共线性和潜变量相关是否异常。
5. **修模纪律**：修正指数只能作为诊断线索；每次增加相关误差或删题必须有题意/测量理论理由并记录。避免反复试模型到“刚好显著”。
6. **Bootstrap**：中介、间接效应和非正态数据优先报告bootstrap置信区间（如5000次、固定随机种子）；间接效应CI跨0时不下支持结论。
7. **多组与稳健性**：跨地区/性别/群体先检查构型、载荷、截距/阈值等测量等值性，再比较路径或潜变量均值；替换估计器、删除高影响样本或按理论替代路径做敏感性分析。

### 4.2 SEM 类型与开源实现

| 问题/数据 | 方法 | 开源实现与注意事项 |
|---|---|---|
| 连续近似正态、反映性量表 | 协方差型CB-SEM | R `lavaan`（ML/MLR）；Python `semopy`；报告估计器和缺失处理 |
| Likert有序题项 | 有序CFA/SEM | `lavaan` WLSMV/DWLS；阈值和类别稀疏需报告，不把题项简单当连续无需说明 |
| 非正态/小样本 | MLR/Bootstrap或贝叶斯SEM | 报告稳健SE、估计器、收敛和先验；小样本不以复杂模型“补救”信息不足 |
| 潜变量路径与预测兼顾 | PLS-SEM | `seminr`/`plspm` 等；明确其预测导向、重抽样方案，不与CB-SEM拟合指标混用 |
| 中介/调节 | latent mediation/moderation | `lavaan`定义间接效应或交互；优先bootstrap，交互项需中心化规则 |
| 多组比较 | Multi-group CFA/SEM | 先测量等值性，再约束路径比较；报告ΔCFI/ΔRMSEA或相应检验及理论依据 |

### 4.3 SEM 最小报告表

```text
模型目的与理论来源｜潜变量/题项/形成性或反映性
样本N、抽样/权重、缺失处理｜估计器与软件/版本
载荷、CR、AVE、区分效度｜χ²、df、CFI、TLI、RMSEA(CI)、SRMR
路径β、SE、p、95%CI、R²｜中介/调节的间接效应与bootstrap设定
修模记录与理论理由｜收敛/Heywood/共线性诊断
多组等值性（如有）｜替代模型/局限/因果措辞边界
```

- EFA：先定义因子数依据（理论、平行分析、碎石图），报告载荷、交叉载荷和旋转；EFA与CFA尽量使用独立样本或交叉验证，不能在同一小样本上反复探索后宣称验证。
- 中介：Bootstrap间接效应区间；中介不是自动因果机制，横截面数据要降低措辞。
- 调节：交互项、中心化/标准化规则、简单斜率或边际效应图；避免只报告交互p值。
- 测量等值性：跨地区/性别比较前依次检查构型、载荷、截距（必要时部分等值），不满足时谨慎比较均值。

## 5. 聚类、降维和机器学习

- PCA/因子分析：区分降维与潜变量测量；训练/测试分离时只在训练集拟合缩放器和降维器。
- K-means：标准化、k候选、轮廓/CH/Davies–Bouldin、稳定性和业务可解释性；随机种子固定。
- 混合型：Gower距离+层次聚类或K-prototypes；说明类别编码和距离定义。
- 分类/回归：Logistic、随机森林、梯度提升、线性/核SVM；小样本优先可解释基线，交叉验证选择超参数。
- 特征选择：Elastic Net或预先理论筛选；不要用全数据先筛特征再交叉验证造成泄漏。
- 模型解释：置换重要性、部分依赖/SHAP需说明相关性解释边界；重要性不是因果影响。
- 类别不平衡：分层交叉验证、class weight或阈值调整；报告PR-AUC、召回率、精确率和混淆矩阵，不能只报准确率。

## 6. 文本与舆情分析

1. **数据治理**：记录来源、抓取日期、去重、广告/机器人、语言、隐私脱敏和抽样；评论可见不等于可无限再传播。
2. **预处理**：自定义词典、停用词、否定词、程度副词、表情/拼写归一化；保留原文只读副本和处理日志。
3. **词频/TF-IDF**：同时给词频和文档频率；不要把词云大小当显著性。
4. **共现/关键词**：固定窗口和共现阈值，报告网络构建规则、节点/边含义和敏感性。
5. **主题模型**：LDA用主题数候选、困惑度/主题一致性与人工可解释性；BERTopic/嵌入聚类要锁定模型版本、随机种子和切分规则，不把主题名当客观事实。
6. **情感**：词典法报告词典版本、否定处理和人工抽样校验；监督分类须有人工标注指南、互评一致性、训练/验证/测试拆分和宏平均F1；BERT等模型不能替代误差分析。
7. **文本回归/分类**：TF-IDF+Logistic作为可解释基线，再与朴素贝叶斯、线性SVM或树模型比较；避免同一用户文本跨训练和测试泄漏。
8. **质性编码**：双人编码、代码本、分歧解决、κ或一致性说明；主题解释保留反例和原文匿名摘录。

## 7. 时间序列、预测与市场测算

- 趋势：移动平均、季节分解、ETS/ARIMA/SARIMA；先画时间序列、检查频率、缺失和结构断点。
- 预测：滚动时间切分，不能随机打乱；报告MAE、RMSE、MAPE（接近0时谨慎）和预测区间，与朴素基线比较。
- 小样本GM(1,1)：只在序列条件与理论理由匹配时使用；报告原序列、参数、后验差检验和与基线比较，不因拟合好就宣称市场必然增长。
- 市场规模：TAM/SAM/SOM或自上而下/自下而上双口径；列出人数、渗透率、频次、客单价和来源，做情景/敏感性区间，禁止单点拍脑袋。

## 8. 因果与实验（需设计支持）

- 随机实验：ITT、处理遵从、随机化平衡、主要结局和预先分析；报告效应区间。
- 准实验：DID检查平行趋势，RDD检查阈值附近连续性，匹配/加权检查协变量平衡；时间序列干预需说明对照与断点。
- 观察数据：DAG、混杂集合、敏感性分析；倾向评分不能自动消除未观测混杂。
- 没有相应设计时使用“相关/关联/预测”，不使用“导致/影响机制已证实”。

## 9. 通用交付字段

每个方法结果至少保存：研究问题、数据版本、分析单位、样本N、权重/聚类、排除与缺失、模型/参数、软件版本、随机种子、效应量/区间、诊断、稳健性、证据边界和图表编号。
