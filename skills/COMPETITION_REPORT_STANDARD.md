# 正大杯本科组报告格式与评分对照（第17届参考）

> 本文件依据仓库整理版 [`../references/竞赛方式计分及报告评审说明.md`](../references/竞赛方式计分及报告评审说明.md)，原始官方附件仍以 `references/第十七届赛制资料/附件6...docx` 与附件3为准。届次更新时必须重新核对，不能把本文件当永久规则。

## 一、硬性格式与提交门槛

| 项目 | 当前参考要求 | 验收动作 |
|---|---|---|
| 报告组成 | 正文与附录分开提交；正文含标题页、摘要页、目录页、正文页 | 分别导出并核对文件 |
| 正文页数 | 不超过65页；系统超页可能拒绝提交 | 以最终PDF页数复核，不用Word估算 |
| 匿名 | 报告和PPT任何一页不得出现参赛校及指导教师信息 | 搜索文字并逐页目视检查页眉页脚、图片和元数据 |
| 地图 | 使用中国地图须采用当届指定的完整最新版底图 | 核对底图文件和图注，避免自行拼接不完整地图 |
| 查重 | >20%取消成绩和资格；>40%按学术不端处理（以当届通知为准） | 提交前按当届平台/规则核验，不能用自测软件替代官方结果 |
| AI | 遵守当届AI工具使用规范，并提交规定的AI附录 | 记录工具、用途、提示词/输出核验和人工修改；不得伪造调查、数据或引用 |
| 展示 | 报告+PPT或报告+现场答辩，比例及时间以当届通知为准；第17届参考为展示8分钟、答辩7分钟 | 单独制作PPT和计时稿 |

## 二、报告100分评分映射

| 评分板块 | 分值 | Skill负责 | 报告必须呈现的证据 |
|---|---:|---|---|
| 研究选题+文献综述 | 20 | 选题、背景 | 实际问题、对象边界、应用价值、可行性、相关文献/文案如何支撑本研究 |
| 方案设计+调查实施 | 30 | 框架、问卷、数据 | 方法选择、样本量、抽样框/限制、调查流程、质量控制、数据处理、独立实施说明 |
| 数据分析与结论 | 30 | 数据分析、图表、结论 | 方法与数据匹配、充分使用数据、诊断/不确定性、结论—证据链、可操作建议 |
| 报告文本+创新性 | 20 | 报告、摘要、图表、全流程 | 结构逻辑、格式规范、文本精炼、图文相辅、易读性和方案/采集/方法/建议中的真实创新 |

> 评分表为合并计分项；整理版注明起评75分、最高不超过95分。评分映射是备赛验收工具，不是保证得分或官方自动评分。

## 三、评分证据链

每个评分板块至少保留：`评审关注点 → 报告位置 → 数据/文献/过程证据 → 局限与待核验`。没有真实数据时交付“分析计划—待执行”，不能用模拟数填入最终报告。

## 四、跨Skill定稿检查

- [ ] 题目小而明确，研究对象、地区、时间和应用问题可界定；文献/文案说明实际如何影响变量、方法或解释。
- [ ] 抽样框、目标总体、可接触总体和实际样本分开；样本量公式参数、设计效应和无效/不响应膨胀可复算。
- [ ] 调查实施有组织流程、培训/质控、拒访/无效样本规则、数据处理日志和独立完成/外部协助说明。
- [ ] 每个统计、文本、聚类、回归或SEM结果都有方法选择理由、诊断、效应量/区间和证据边界。
- [ ] 结论回应研究问题并回链图表/表格；建议有主体、动作、抓手、指标、期限，不把横截面关联写成因果。
- [ ] 正文与附录、摘要与正文、图表与数据的数字一致；图表有编号、标题、来源、分母/口径和首次正文引用。
- [ ] 版式与页数通过最终PDF检查；匿名、地图、查重和AI附录按当届通知复核。
