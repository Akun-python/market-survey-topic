# 正大杯绘图：证据链与验收卡

本卡将 MIT 许可 Superpowers 的「先厘清需求」与「完成前验证」两项原则转化为市场调查图表验收；原始 Skill 和许可证见 [`../../_third_party/README.md`](../../_third_party/README.md)。这不是官方评分细则，不保证获奖。

## 1. 图表设计卡（制作前）

```text
编号与正文位置：图 4-2 / 第四章第一处引用
目的与受众：让评委看到不同年龄组对服务的满意度差异
可证实的主张：仅报告组间样本差异，不声称年龄造成差异
数据来源与版本：data/clean.csv，问卷 Q12；生成日期与脚本版本
分母与缺失：各组有效样本 n；缺失剔除规则、权重、时间窗
图型与替代：排序条形 + 95% CI；不选无误差棒的均值柱图
风险：小样本、非概率样本、组间基数不等、混杂因素
```

## 2. 图型与统计口径

- 百分比须有分母；多选题占比合计可超过 100%，必须注明“多选”。
- 比较均值须提供各组 n、量表范围和不确定性；误差棒类型写在图注里。
- 相关/回归系数图注明模型、控制变量及区间；不以相关暗示因果。
- 聚类投影（PCA/t-SNE/UMAP）仅用于展示空间结构；t-SNE 的坐标距离不等于原始变量距离，不能用散点图证明分类准确或因果。
- 时间趋势需标识观测期、缺失时点、预测起点和区间来源；没有可估计区间时不要画虚假的置信带。
- 地图须注明行政区版本、数据年份、缺失区域/不适用区域；慎用面积视觉误导。
- 桑基图每层口径与流量守恒必须核对；若样本可多选，不能伪称互斥转化漏斗。
- 雷达图不同指标必须同向、同范围且标注量纲转换；若只是简单排名，优先条形图。

## 3. 文件与视觉验收

| 检查项 | 核验方式 | 未通过时 |
|---|---|---|
| 数据与图一致 | 抽取绘图输入、与分析表对应数值比对；比例验算 | 回退清洗口径，不直接改图上标签 |
| 中文字体和负号 | 渲染图目视 + 字体检查 | 换可用 CJK 字体并重新导出 |
| 尺寸与清晰度 | 核对 PNG 像素、dpi 元数据及插入 Word 后实际大小 | 提升尺寸/字体，不盲目提高 dpi |
| 色彩与可读性 | 灰度/色盲模拟或低色彩对比下检查区分度 | 加线型/标记/直接标签 |
| 无遮挡 | 查看完整图、长标签、图例、注释、边界 | 改布局、换行、扩展边距 |
| 来源和口径 | 图下注明来源、年份、问卷题号、分母、权重 | 补注；无法核实则停止作为证据 |
| 正文引用 | 图号、图题、清单、首次引用和结论逐一映射 | 修正顺序或删除无归属图 |
| 演示与实证区分 | 示例图显式标“演示/模拟数据” | 删除误导性实例、重新标注 |
