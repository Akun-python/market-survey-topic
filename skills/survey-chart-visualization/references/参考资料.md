## 二、工具栏与版本说明

| 工具 | 用途 | 备注 |
|---|---|---|
| matplotlib | 统计图表（柱/条/雷达/箱线/热力） | 中文字体：SimHei / Microsoft YaHei（Windows）、Noto Sans CJK SC |
| seaborn | 统计可视化（热力图、分布图） | 依赖 matplotlib |
| scikit-learn | PCA / t-SNE 降维（聚类散点） | 需 sklearn |
| plotly | 交互图（静态导出用 kaleido） | 开源 |
| Apache ECharts | 桑基/水波/玫瑰/和弦等高级图型 | 开源，Web 导出 |
| wordcloud | 词云（辅助） | 必须指定系统中文字体路径 |
| draw.io / PowerPoint / yEd | SEM 路径图（矢量） | 导出 PNG 300dpi 后嵌入报告 |
| Gephi | 语义共现网络图 | 开源 |
| yellowbrick | KElbowVisualizer（CH/肘部选簇） | 开源 |
| SciencePlots | 论文样式主题 | `pip install SciencePlots` |

## 三、图表规范速查（三线表与其他）

- **三线表**：顶线、表头底线、表底底线；表头有单位说明；
- **图题在图下 / 表题在表上**，居中，编号连续（图 1、表 1）；
- **来源注** 与 **注**（必要解释）位于图表下方；数据不一致须在注中说明；
- 导出版本：PNG（300 dpi）+ PDF（矢量）；Word 引用 PNG，最终印刷/PDF 用矢量。

## 四、配色建议

- 主题色 ≤5 色，统一全程；推荐低饱和莫兰迪色或 Okabe-Ito 色盲友好色板；
- 禁用：彩虹色、3D 饼图、无意义渐变。
