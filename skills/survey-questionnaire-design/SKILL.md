# SK3 问卷设计：把"变量清单"变成可填、可测、可分析的问卷

> **一句话**：好问卷的标准不是"问得全"，而是「**每一道题都能对应一个分析用途，每一道量表题都能对应一个潜变量，填完 30 份预调查能证明它信效度达标**」。

## 一、定位与适用场景

- **用在报告哪里**：方案章（问卷结构/量表设计说明）+ 附录（问卷全文）。
- **用在什么阶段**：SK2 变量清单完成后 → 预调查 → 定稿。也可配合 SK4（预调查信效度）。
- **不适用**：纯访谈研究（改用 SK1/访谈提纲）；已有成熟量表且仅微调时也要标注来源。

## 二、输入清单

| 输入 | 具体要求 |
|---|---|
| 变量清单与假设 | 来自 SK2：研究点 → 维度 → 假设 H1–H4 |
| 量表母版（可选） | 成熟量表（TAM、TPB、信任、涉入度等），标注来源文献 |
| 访谈/扎根结果 | 若有深度访谈，编码后的范畴 → 题项来源 |
| 目标人群语言习惯 | 面向农户/老年人等群体要"口语化 + 名词解释"，先做问卷说明 |

## 三、标准步骤

### 第 1 步｜问卷整体结构（五段式）

| 段落 | 内容 | 要点 |
|---|---|---|
| ① 卷首语 | 身份、目的、保密、时长、知情同意 | 必须含"匿名、仅用于学术研究、数据保密"；注明预计时长 |
| ② 筛选题 | 是否符合目标人群 | 如年龄区间、是否为目标产品用户/农户 |
| ③ 基本信息 | 人口统计 + 关键分类变量 | 性别/年龄/学历/收入/职业/地区；与研究假设一一对应 |
| ④ 核心题区 | 认知 → 态度 → 意愿 → 行为 | 量表题为主；按研究点顺序排列 |
| ⑤ 意愿与开放题 | 支付意愿/推广意愿/建议 | 支付给"金额阶梯"；开放题 1 道收尾 |

### 第 2 步｜题项生成（三来源）

1. **成熟量表改造**：引用文献版本，按场景微调措辞，**必须标注来源**（如"个性匹配度/专业性/吸引力"改编自前人量表）。
2. **扎根理论自开发**：访谈编码 → 范畴 → 题项（如 875 参考点 → 32 范畴 → 32 题量表，维度命名取自文献，示例口径）。
3. **专家/预访谈补充**：高校教授 + 行业人员 + 目标人群代表做可读性审查（如"2 名教授、2 名硕博、5 名居民"）。

### 第 3 步｜量表题规范（核心）

- 李克特 5 级为主（非常不同意→非常同意），**锚点全卷统一**；
- **每个潜变量 ≥3 题**（信度需要）；正反向题结合；
- 一个潜变量一组题，用矩阵量表/表格呈现；
- 专业术语首次出现给解释（卷首定义 + 示意图/举例）。

### 第 4 步｜跳转逻辑

- 未接触者跳过体验题（如第 1 题选"从未" → 跳第 13 题）；
- 购买与否分流（如第 10 题：买过 → 跳 12 题；未买 → 11 题）；
- 线上版与纸质版跳转必须一致，预调查逐人核验。

### 第 5 步｜防伪与质量控制题

- **防伪题**：1 道"该题请选择 5"；
- 填写时长记录（< 中位数 × 1/3 判无效）；
- 规律作答识别（连续同值 ≥8 题判无效）；
- 质量校验扩展：设"质量检测题"（前后同题干重复作答）与关键题必答，录入后结合**答题时长 + 重复率**双重判废；预调查可用 **27% 高低分组 t 检验**做题项区分度。

### 第 6 步｜题量与排版

- **≤40 题、≤8 分钟**（预调查 3 人计时确认）；
- 选项互斥且穷尽（加"其他___"）；
- 敏感题目后置；收入用区间不用绝对值；
- 量表题干避免"双重询问（double-barreled）"与诱导性措辞。

### 第 7 步｜预调查 → 信效度 → 修订 → 定稿

```
预调查 30–50 份
  → 信度：Cronbach's α ≥ 0.7（各维度单算）
  → 效度：KMO ≥ 0.6、Bartlett 球形检验 p < 0.05
  → 修订：删低载荷题项、改歧义表述、调顺序（记录删改理由）
  → 定稿 → 正式调查
```

> 常见呈现：预调查与正式调查各给一份 α 表 + 效度表，口径一致。

## 四、方法与模板

**维度—题项—来源对照表（交付物 1）**：

| 潜变量 | 题号 | 题项 | 来源（文献/扎根/自编） | 预期方向 |
|---|---|---|---|---|
| 感知有用性 | Q9a–9c | 购买参保能保障收入… | 改编自 TAM（Davis, 1989） | + |

**卷首语模板**：

> 您好！我们是〔学校〕学生，为参加全国大学生市场调查与分析大赛，正在进行〔主题〕调查。本问卷匿名填写，答案无对错，数据仅用于学术研究并严格保密，预计占用您〔3–8〕分钟。感谢您的支持！

**预调查修订记录表（交付物 2）**：

| 题号 | 原表述 | 问题 | 修订后 | 理由/数据依据 |
|---|---|---|---|---|

## 五、产出模板

```markdown
### 附录：调查问卷（终稿）
（① 卷首语 → ② 筛选题 → ③ 基本信息 → ④ 核心题区（维度分节） → ⑤ 意愿/建议 → 开放题）

正文方案章需呈现（3 段以内）：
- 问卷结构与维度（引用维度-题项对照表）
- 量表来源说明（成熟量表标注文献）
- 预调查信效度结果 + 修订过程
```

## 六、验收标准（逐条打勾）

- [ ] 每个维度 ≥3 题，与假设一一对应（对照 SK2 变量清单）
- [ ] 卷首语含：目的、匿名、保密、时长、知情同意
- [ ] 跳转逻辑线上版与纸质版一致，预调查逐份核验
- [ ] 含 ≥1 道防伪题 + 时长/规律作答判废规则
- [ ] 预调查：各维度 α ≥ 0.7，整体 KMO ≥ 0.6、Bartlett p < 0.05
- [ ] 试填 3 人计时 ≤ 8 分钟；总题量 ≤ 40
- [ ] 无非衡量题（双重询问）、无诱导性措辞、术语有解释
- [ ] 问卷全文进附录，正文有结构说明

## 七、报告呈现要求

- 问卷全文作为**附录**（评审鼓励附原始数据与工具）；
- 正文方案章 1–2 页说明：结构、维度来源、预调查信效度（表和修订记录可以随时给出）；
- 量表设计若来自扎根理论，需附编码示例表（开放式→主轴→选择性编码各一例）。

## 八、常见坑

1. **维度与题项脱节**：变量清单说 4 个维度，问卷只测了 3 个。
2. **量表题直接问意愿**：问"愿不愿意"而不是给情景与锚点（可给出"支付金额阶梯"，或用 6 张刺激素材图作参照）。
3. **选项不互斥**：年龄段重叠、收入区间重叠。
4. **跳转错乱**：纸质排版与线上逻辑不一致，预调查没发现。
5. **卷首语缺知情同意**：敏感赛事评审会看伦理规范。
6. **预调查只做信度不做效度**：只说 α=0.9，没有 KMO/Bartlett。
7. **题量超 50**：填写 >10 分钟 → 数据质量断崖式下降。
8. **条款不解释**：专业词直接出现在题干（农户/老年受访者看不懂 → 废卷率高）。

## 九、开源工具链（完整命令见 `OPEN_SOURCE_STACK.md`）

- **在线答题（开源）**：LimeSurvey / KoboToolbox / ODK Collect（可导出 CSV/SPSS，自带答题时长与 IP 字段）；
- **信效度**：Python `factor_analyzer`（KMO、Bartlett、EFA 载荷）、`pingouin`（Cronbach α、ICC）；R 包 `psych`（alpha/KMO/fa）；CFA 用 `lavaan`（R）或 `semopy`（Python）；
- **无 SPSS 团队**：jamovi / JASP（开源 GUI，含信效度与 EFA 模块）或 GNU PSPP；
- **读数据**：`pandas` + `pyreadstat` 直接读 SPSS `.sav` 导出，预调查与正式调查口径一致。

## 十、写法要点（对照历届获奖作品自检）

高分作品的问卷与信效度章节通常具备以下特征：

1. 问卷结构五段式完整，正文给出"维度—题项—来源"对照表；
2. 每个潜变量 ≥3 题、锚点统一，跳转与防伪题齐全；
3. 预调查与正式调查均报告 α、KMO、Bartlett，含修订记录表；
4. 量表来源可追溯（成熟量表标注文献；自编题附扎根编码示例）；
5. 附录放问卷全文（含卷首语），正文的结构说明能对着附录逐条找到；
6. 面向特殊人群时给出"问卷说明"（单选/多选/填表示例）。
