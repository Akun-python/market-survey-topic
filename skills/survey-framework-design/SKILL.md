# SK2 调查框架设计：把"研究问题"翻译成"可执行的调查方案"

> **一句话**：方案设计是整份报告的基石（20 分），评委看的是「**目的可检验、抽样有依据、样本量算得出、每一步能落地**」。

## 一、定位与适用场景

- **用在报告哪里**：第二章/第三章"研究设计（调查方案）"，含研究框架图、抽样设计、样本量与调查方式。
- **用在什么阶段**：背景定型之后、问卷设计之前。
- **不适用**：纯二手数据研究（可简化抽样章节，但样本来源仍须说明）。

## 二、输入清单

| 输入 | 具体要求 |
|---|---|
| 选题卡 + 研究点 | 来自 SK1 的输出：两个研究点、H1/H2 假设 |
| 目标地区基础数据 | 行政区划、人口、户数（用于分层与样本分配） |
| 抽样框线索 | 乡镇/街道名录、社区名单、行业协会名录 |
| 调查方式约束 | 团队人数、预算、可实地天数、线上渠道 |
| 问卷草稿 | 可后置，但需先有变量清单 |

## 三、标准步骤

### 第 1 步｜写清调查目的（≤3 条）
每条 = **回答什么问题 + 用什么数据 + 服务哪个章节**。禁止"了解现状、提出建议"式口号。

### 第 2 步｜界定总体与对象
- 总体：谁（人群/主体）、范围（市/区/县）、时间窗；
- 对象：纳入标准 + 排除标准（如"18–35 岁、近 3 个月买过 X 的消费者"）；
- 单位：个人 / 家庭 / 企业 / 村集体。

### 第 3 步｜拆解调查内容为变量清单
每个研究点 → 维度 → 题项 → 假设：

| 研究点 | 维度（潜变量） | 观测变量（题项方向） | 假设 |
|---|---|---|---|
| 研究点 1：认知现状 | 了解程度 / 渠道 / 认知偏差 | 是否听过、了解哪几项技术、信息来源 | H1：认知与人口特征相关 |
| 研究点 2：意愿与影响因素 | 感知有用性 / 易用性 / 主观规范 / 信任 | 李克特各 3 题 | H2–H4 |

### 第 4 步｜画研究框架图（必须有）
结构：**研究背景 → 理论/假设 → 变量与问卷 → 数据采集 → 分析模型 → 结论建议**。先画文字版再补图：

```
现象与缺口 → 研究问题（2 个）→ 理论模型与假设（H1–H4）
   → 变量体系 → 问卷/访谈 → 抽样与数据采集
   → 分析（描述→差异→画像→建模）→ 结论与建议
```

> 框架图里的每个方框必须能在正文章节中找到对应（图上有"文本挖掘"，正文就必须有一章）。

### 第 5 步｜选调查方式并说明理由

| 方式 | 适用 | 说明 |
|---|---|---|
| 线上问卷 | 覆盖面广、成本低 | 通用首选，注意样本自选偏差 |
| 线下拦截/入户 | 特定人群（农户、老年人） | 入户/蹲点拦截，配赠品提高配合度 |
| 深度访谈/焦点访谈 | 探索阶段、量表开发 | 前期质性探索，产出题项来源 |
| 二手数据 | 宏观背景、行业规模 | 政策与行业数据，标注来源 |
| 网络文本 | 舆情与态度 | 平台公开评论，配情感分析 |
| 网络自选 + 受访者驱动抽样（RDS） | 圈子性强、难以用名单覆盖的人群（租客、散户、爱好者） | 先访谈 5 名种子用户，再滚动招募扩充样本 |
| 试吃/体验实验 + 评分 | 产品口味、包装、价格等属性比较 | 组织 200+ 名代表按 6 个维度评分（外观/分量/价格/口味/便利性/回购意向） |
| POI 爬取 + 空间分析 | 区域配套现状（商业/教育/医疗/绿化） | 爬取地图 POI 数据做空间分布分析 |

> 不要求"都用问卷"；评审明确提示"根据情况选择适当的方法"。

### 第 6 步｜抽样设计（20 分的核心）
**① 确定抽样框**：能拿到名单的优先（乡镇农业人口表、社区户册、行业协会名录）。

**② 设计多阶段抽样**（通用三阶段组合，最完整）：

| 阶段 | 抽样单元 | 抽样框 | 方法 | 样量 |
|---|---|---|---|---|
| 一阶段 | 乡镇/区 | 全市乡镇（按农业人口/常住人口） | **PPS**（概率比例规模，放回不等概率） | 抽 5–10 个 |
| 二阶段 | 村/社区 | 入样乡镇的村/社区名单 | **分层抽样**（按人口比重分配） | 抽 30 个左右 |
| 三阶段 | 农户/居民 | 入样村户册 | **简单随机抽样** | 每点约 20 户 |

**③ 计算样本量**：

```
n₀ = Z² · π(1−π) / E²
Z  = 置信水平对应值（95% → 1.96）
π  = 目标比例（无先验取 0.5 最保守；有预调查取预调查比例）
E  = 允许误差（0.05 → ±5%）
设计效应 deff：多阶段/整群抽样 >1，一般取 1.2–2.0
有效样本 n = n₀ × deff；发放量 N = n ÷ 有效回收率（按 80–90% 上浮）
```

> 例：Z=1.96、π=0.5、E=0.05 → n₀=**384**；π=0.25 → **288**。示例口径：预调查目标行为比例 25%、取 n≥288，实发 558、有效 497（演示值）。
> 复杂抽样放大链条：n₀=384 → × 设计效应 deff≈1.8 → ≈692 → ÷ 有效率 90% → 计划约 768；实发 1919、有效 1749、有效率 93.13%（演示口径）。**deff 的取值必须在文中说明理由**。
> 大样本示例口径：实发 2000、有效 1673（有效率 83.65%）、极限误差 2.831%（演示口径）。

**④ 编制样本分配表**（地区 × 人口 × 比例 × 分配份数），加总必须等于发放量。常见做法：分层按层内规模比重分配，附区划代码法（给每个单元编代码、随机落点）。

### 第 7 步｜安排预调查
- 30–50 份（规范示例：50 份、有效 42）；
- 目的：验证问卷可读性、跳转逻辑、时长、选项分布；
- 产出：修订记录（删/改/增题项，并说明理由）。

### 第 8 步｜排进度甘特
准备（选题/文献/方案）→ 预调查 → 正式调查 → 数据清洗 → 分析 → 撰写，标起止日期，并加"组织工作/人员分工/经费预算"小节。

## 四、方法与公式

| 要素 | 公式/规则 |
|---|---|
| 样本量 | `n = Z²π(1−π)/E² × deff`，再按回收率上浮 |
| PPS 抽样 | 按规模累计编制代码范围，随机数落点即中选单位（代码见 OPEN_SOURCE_STACK.md） |
| 分层分配 | 按层内规模比重分配（比例分配） |
| 误差控制 | 报告极限误差（如 2.83%），说明置信水平与计算口径 |
| 冗余设计 | 发放量 ≈ 有效样本 ÷ 预期有效率（80–90%） |

## 六、验收标准（逐条打勾）

- [ ] 调查目的 ≤3 条，每条可检验且对应章节
- [ ] 总体、对象、纳入/排除标准明确
- [ ] 每个研究点都有维度与假设（H1、H2…）
- [ ] 研究框架图与后文章节一一对应
- [ ] 抽样方法说明"为什么这样抽"（科学性论证，不是罗列）
- [ ] 样本量有公式、参数取值、冗余与回收率说明
- [ ] 样本分配表加总 = 发放量
- [ ] 预调查份数与修订回路写清
- [ ] 方案篇幅 4–6 页，无空话

## 七、报告呈现要求

- 位置：第二/三章；篇幅 **4–6 页**
- 必配：研究框架图 1 张、抽样方案表 1 张、样本分配表 1 张
- 公式（样本量）给编号并解释参数；表格三线表
- 图/表编号续全文（图 3-1、表 3-1 或全文连续编号，二选一，全报告统一）

## 八、常见坑

1. **目的写成口号**："了解市场现状并给出建议" → 无法对应数据与章节。
2. **抽样框不存在**：写"随机抽取 XX 市居民"，但名单拿不到 → 不可行。
3. **样本量拍脑袋**：500、1000 无公式 → 评审扣分。
4. **只说"随机抽样"**：不写阶段、比例、计算方法 → 不科学。
5. **框架图与正文脱节**：图上没有文本挖掘，正文却有一章 → 对不上。
6. **无预调查**：直接发 1000 份 → 问卷缺陷放大。
7. **回收率假设过乐观**：按 100% 发放 → 有效样本不足，返工。
8. **多阶段但不知 deff**：整群抽样仍按简单随机报误差 → 高估精度。

## 九、开源工具链（完整命令见 `OPEN_SOURCE_STACK.md`）

- **抽样框与随机化**：Python `numpy.random`（PPS 累计代码范围随机落点）；R 包 `sampling`（PPS/分层整套函数）、`RDS`（受访者驱动抽样）；
- **复杂抽样与权重**：R 包 `survey`——多阶段/整群抽样必须按**设计效应与权重**报告置信区间；
- **样本量/功效**：OpenEpi（开源网页计算器）或 Python 按公式自算并写进脚本（进附录）；
- **问卷平台（开源）**：LimeSurvey（GPL，自部署）、KoboToolbox / ODK Collect（田野与离线场景）；
- **甘特**：GanttProject（开源）或 draw.io 模板。

## 十、写法要点（对照历届获奖作品自检）

高分作品的方案章节通常具备以下特征：

1. 调查目的 3 条、各自可检验且对应后文章节；
2. 抽样写全"阶段 × 单元 × 抽样框 × 方法 × 样量"，并论证"为什么这样抽"；
3. 样本量有公式、参数（Z/π/E/deff/回收率）与计算过程，冗余设计写明；
4. 样本分配表加总 = 发放量，分点分配比例可追溯；
5. 预调查份数、修订回路与质量控制（前/中/后）写清；
6. 单一问卷不足时，用多方法组合（访谈/实验/爬虫/文本）补强；
7. 进度甘特 + 组织分工 + 经费概算，体现可执行性。
