# 参考资料（report-writing / 报告撰写与润色）

## 一、赛制与评分（必读）

| 文件 | 用途 |
|---|---|
| `../../../references/竞赛方式计分及报告评审说明.md` | 报告满分 100 分评分表；正文页数上限（以当届通知为准）；正文与附录分开提交 |
| `../../../references/第十七届赛制资料/` | 当届时间线、提交方式与格式要求 |

## 二、格式规范参考

- 章节层级：一级 `一、`，二级 `（一）`，三级 `1.`（全篇统一，不混用）
- 参考文献：GB/T 7714—2015（正文上标 [1]，文末一一对应）
- 图表：图题下、表题上；三线表；编号全文连续；图目录/表目录与正文一致
- 摘要页：独立页（目标 1600–2000 字，约 2 页，写法见 SK7）

## 三、工具（开源，可复现链）

- Markdown → PDF/Word：`pandoc` + xelatex（中文用 xeCJK）或 `quarto`；`typst` 轻量备选
- docx 直出：`python-docx` 套模板；LibreOffice 命令行批量转 PDF
- 版本管理：`git`（每章一提交，留痕可回滚）
- 文献引用：Zotero + Better BibTeX（GB/T 7714 csl 文件）

## 四、润色与校验工具（可选）

- 错别字与标点：Word 校对 / LanguageTool（开源）
- 一致性检查：脚本核对术语、单位、数字（摘要 vs 正文的样本量/有效率）
- 结构审查：目录与标题一一对应；研究闭环映射表（问题→假设→变量→数据→方法→结论）
