# SK4 数据分析：让每个结论都有检验支撑

> **一句话**：数据分析不是"把能跑的方法都跑一遍"，而是按「**数据 → 发现 → 证据链**」组织，做到评审口径的"数据运用充分、分析方法科学合理、结论有数据支撑"（25 分）。

## 一、定位与适用场景

- **用在报告哪里**：正文分析章（通常第三–七章），覆盖"描述 → 差异 → 画像 → 建模 → 文本 → 预测"。
- **用在什么阶段**：数据回收与清洗后、结论撰写（SK8）前。
- **不适用**：质性为主的报告（只做扎根编码时直接用访谈分析，不套本金字塔）。

## 二、输入清单

| 输入 | 具体要求 |
|---|---|
| 问卷终稿 + 回收数据 | 线上导出 + 线下录入（Excel/SPSS） |
| 维度-题项对照表 | 来自 SK3，用于反向题重编码与维度聚合 |
| 二手数据 | 宏观/行业序列（预测与中介用） |
| 网络文本数据（可选） | 评论区/访谈文本（L5 用） |

## 三、标准步骤

### 第 0 步｜数据清洗（先于一切分析）

| 检查项 | 规则 | 示例/口径 |
|---|---|---|
| 无效判定 | 时长 < 中位数 1/3、规律作答、逻辑矛盾（前后冲突）、关键题缺失 | 示例：实发 558 → 有效 497，有效率 89.06%（演示值） |
| 编码 | 反向题重编码；多选题拆布尔列；文本题编号 | 附编码说明表 |
| 缺失处理 | 缺失 < 5%：个案删除或均值/众数插补；> 5%：说明原因并谨慎处理 | — |
| 录入抽检 | 随机抽 10–15% 复核录入，不一致即纠正并复抽 | 录后抽检 10–15% |

### 第 1 步｜信效度与随机性证明（数据"可信"的底气）

- 信度：各维度 Cronbach's α ≥ 0.7（预调查与正式调查各一份 α 表）；
- 效度：KMO ≥ 0.6 + Bartlett p < 0.05（探索性）；验证性因子分析（CFA）另报 χ²/df、CFI、RMSEA；
- 随机性：游程检验（样本是否随机）；
- 代表性：样本结构与总体对比（性别/年龄/学历占比 vs 市统计年鉴）。

### 第 2 步｜L1 描述统计（样本"长什么样"）

- 分类变量：频数 + 占比（配图，见 SK5）；
- 连续变量：均值 ± SD、中位数、箱线图；
- 每个研究点的核心变量先做单变量描述（认知程度分布、意愿均值）。

### 第 3 步｜L2 差异性检验（"有没有差异"）

| 情景 | 方法 | 输出 | 示例 |
|---|---|---|---|
| 分类 × 分类 | 卡方独立性 + 交叉列联 | χ²、p、Cramér's V | 人口特征 × 认知交叉列联 |
| 分类 × 连续 | ANOVA / Kruskal–Wallis | F、p、η² | 聚类后组间差异检验 |
| 多指标排序 | Friedman 秩检验 | χ²、秩均值 | 多指标关注度排序 |

### 第 4 步｜L3 聚类与用户画像（"能分成几类人"）

| 数据形态 | 方法 | 取簇数 | 可视化 | 适用示例 |
|---|---|---|---|---|
| 数值型 | K-means | 肘部图 / **Calinski–Harabasz（CH）指标** | t-SNE 散点 + 雷达图 | 数值型画像，k 由 CH/肘部定 |
| 混合型（数值+分类） | K-prototype | 同上 | 同上 | 混合型数据画像 |
| 自动定簇 | TwoStep 聚类 | 内置 BIC/AIC | 集群摘要 | 自动定簇画像 |

画像命名：给每类一个易记标签（如"忠诚型/沉睡型/迷茫型"），并用画像表 + 雷达图呈现。

### 第 5 步｜L4 解释性建模（"什么因素、以什么路径影响"）——见下方决策树

### 第 6 步｜L5 文本挖掘（"人们怎么说"）

| 目的 | 方法 | 示例 |
|---|---|---|
| 高频主题 | 分词 + 词频/词云（配词频条形图，勿只用词云） | 认知词频/网络词云 |
| 主题聚类 | LDA 主题模型（困惑度/一致性选 K） | LDA 主题分类及困惑度选择 |
| 关键词 | TF-IDF；Word2vec 词汇散点 | TF-IDF 关键词提取 |
| 情感 | 情感词典逐词匹配；深度学习（CNN/BERT）分类 | 情感词典 + 深度学习双方法、情感倾向分析 |
| 共现网络 | 语义网络共现 + Gephi 可视化 | 文献/评论语义网络图 |

### 第 7 步｜L6 市场预测（"未来多大"，可选）

| 情景 | 方法 | 示例 |
|---|---|---|
| 单序列、小样本 | 灰色关联 → GM(1,1) | 历史序列外推预测 |
| 多因素 | 多元线性回归（先算灰色关联排序剔变量） | 回归预测 + 双模型对比 |
| 综合评价 | 灰色模糊评估（AHP/熵权定权 → 隶属度） | 多指标发展水平评估 |

### 第 8 步｜稳健性/对比（加分项）

- 至少一种替代方法或子样本复验（如 GM(1,1) 与多元回归对比；SEM 修正前后对比、调节作用检验）；
- 敏感性：改变聚类数/剔除异常样本看结论是否稳定。

## 四、方法选择决策树（研究问题 → 方法）

```
问"不同群体是否有差异？"       → 卡方 / ANOVA / Friedman（L2）
问"能分成几类人？"             → K-means / K-prototype / TwoStep（L3）
问"哪些因素影响意愿（潜变量）？" → SEM（结构方程）→ 拟合 → 修正（L4）
问"是否购买/是否愿意（0/1）？"  → 二元 Logistic（L4）
问"意愿等级（有序）？"          → 有序 Probit / 有序 Logit；支付意愿用 CVM（L4）
问"影响路径/中介、调节？"       → 中介效应（Bootstrap/Sobel）+ 调节（交互项）（L4）
问"人们怎么说、情绪如何？"      → 词频/共现/LDA/TF-IDF/情感词典/深度学习（L5）
问"未来规模多大？"              → GM(1,1) / 多元回归 / 灰色模糊评估（L6）
问"影响变量太多、需要筛选？"     → 弹性网络（ElasticNet）/ 随机森林特征重要性（L4）
问"多类别结果（买什么/为何不买）？" → 无序多分类 Logistic（L4）
问"分类变量降维/偏好结构？"      → 分类数据主成分分析（CATPCA）/ 关联规则（L4）
问"多指标综合满意度/优先级？"     → AHP 定权 + 模糊综合评价；IPA 重要度-满意度（L4）
问"因素与目标关联强弱排序？"      → 灰色关联度（L6）
```

> 选方法必须写"为什么"：例——"因变量为四档有序支付意愿，故采用有序 Probit"；"特征含数值型与分类型，故采用 K-prototype"；"缺先验、小样本时序，故采用灰色系统 GM(1,1)"。

**L4 扩展：即插即用方法卡**

| 方法 | 解决什么问题 | 开源实现 | 适用示例 |
|---|---|---|---|
| 弹性网络（ElasticNet） | 变量多、共线性，先筛后回归 | `sklearn.linear_model.ElasticNet` | 高维变量筛选 |
| 随机森林特征重要性 | 人口学变量对偏好/意愿的相对重要度排序 | `sklearn.ensemble.RandomForestClassifier` | 偏好轮廓与变量排序 |
| 无序多分类 Logistic | 多类别结果（如五类购买者/三类未购买者） | `statsmodels` MNLogit | 多类别消费者画像 |
| CATPCA（分类数据主成分） | 分类变量降维、成分载荷图 | R `Gifi`；Python 用哑变量 + PCA 近似 | 不选择原因载荷图 |
| 二元 Logistic + H-L 检验 | 二分类意愿 + 拟合优度检验 | `statsmodels` Logit + 分箱手算 H-L | Logistic 拟合诊断 |
| AHP + 模糊综合评价 | 多指标权重与综合评分 | numpy 手写（特征向量法 + 隶属度） | 满意度权重与综合评分 |
| IPA 重要度-满意度 | 指标优先级/改进象限 | Python 手写 + 散点图 | 满意度改进象限 |
| 灰色关联度 | 因素与目标关联排序 | numpy 手写（分辨系数 0.5） | 因素关联排序 |
| 轮廓系数/CH 选簇对比 | 聚类 k 的选择依据 | `sklearn.metrics` | 聚类 k 的确定 |

## 五、统计报告规范

- 每个检验给出：**统计量 + 自由度 + p 值**（p<0.05 用 *、p<0.01 用 **、p<0.001 用 ***，脚注注明口径）；
- 回归/模型给：系数、标准误、显著性；整体 R² / 伪 R²；拟合指标（SEM：χ²/df<3、RMSEA<0.08、CFI/TLI≥0.9、SRMR<0.08）；
- 表格按"变量 / 系数 / 显著性"排列，表下加注（* * * * 含义、样本量 N）；
- 禁止只写"显著"不给数值。

## 七、验收标准（逐条打勾）

- [ ] 每个结论对应 ≥1 个检验/模型输出（结论—证据链表非空）
- [ ] 方法选择有理由说明（不堆砌方法）
- [ ] 统计量、自由度、p 值齐全，无"显著"无数值
- [ ] SEM 类模型有拟合评价 + 修正说明
- [ ] 聚类给出取簇数依据（CH/肘部/BIC/轮廓系数）
- [ ] 文本分析不只有词云（至少一个统计或模型输出）
- [ ] 图表数字与正文文字一致（交叉核对）
- [ ] 数据清洗过程可复现（脚本进附录）
- [ ] 分析结论与 SK2 假设逐条对应（H1–H4 有结论）

## 八、常见坑

1. **描述统计当主体**：五章全是百分比 → 评委觉得没深度。
2. **先定方法再找数据**：想用 SEM 但量表没按潜变量设计 → 返工。
3. **p 值缺自由度和统计量**：无法复核。
4. **聚类不检验**：不说明 k 怎么来的。
5. **SEM 不做拟合修正**：模型拟合不合格直接给结论。
6. **结论超出数据**：只测了 A 市，结论写到全国（生态谬误）。
7. **文本分析只有词云**：好看但不可检验。
8. **数字前后矛盾**：摘要说有效率 89%，正文却是 80%。

## 九、开源工具链（完整命令与脚本见 `OPEN_SOURCE_STACK.md`）

- **数据**：`pandas` + `pyreadstat`（读 SPSS `.sav`）；`numpy` / `scipy.stats`（卡方、Friedman、ANOVA、相关）
- **回归与离散选择**：`statsmodels`（OLS、Logit、MNLogit、OrderedModel + H-L 拟合检验）
- **SEM**：`semopy`（Python，输出 χ²/df、RMSEA、CFI、TLI）；R 版 `lavaan`
- **中介/调节**：`pingouin.mediation_analysis`（Bootstrap 中介）；调节用交互项回归
- **聚类/降维/树模型**：`sklearn`（KMeans、silhouette、CH、PCA、t-SNE、RandomForest、ElasticNet）
- **选簇可视化**：`yellowbrick`（KElbowVisualizer 自动标注 CH/肘部）
- **文本**：`jieba`、`snownlp`/`cnsenti`（中文情感）、`gensim`（LDA）+ `pyLDAvis`、`wordcloud`
- **无 SPSS 环境**：jamovi / JASP / GNU PSPP（图形界面跑信效度、回归、方差）
- **可复现**：Jupyter 记录过程 + `pip freeze > requirements.txt`，脚本进附录

## 十、写法要点（对照历届获奖作品自检）

高分作品的分析章节通常具备以下特征：

1. 金字塔完整：描述 → 差异 → 画像 → 建模（必要时加文本与预测），层间有逻辑递进；
2. 每个方法都有"为什么用"的说明（匹配数据结构与研究问题）；
3. 聚类给出取簇依据（CH/肘部/轮廓系数），并有画像表 + 雷达图；
4. SEM 报拟合指标（χ²/df、RMSEA、CFI/TLI）与修正过程，假设逐条给支持与否；
5. 文本分析至少有一个统计或模型输出（LDA/情感/TF-IDF），不只放词云；
6. 强调稳健性（替代方法、子样本复验、敏感性）；
7. 全章结尾给出"结论—证据链表"，数字与摘要一致。
