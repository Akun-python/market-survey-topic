# 参考资料（conclusion-writing / 结论撰写）

## 一、赛制与规则依据

| 文件 | 用途 |
|---|---|
| `../../../references/竞赛方式计分及报告评审说明.md` | "分析与结论 25 分"评分口径：结论严谨、有数据支撑、建议可操作 |
| 当届赛制资料 | 页数限制、提交方式（以当届通知为准） |

## 二、结论—建议写法对照（两种组织方式）

| 组织方式 | 适用 | 要点 |
|---|---|---|
| 方式 A｜主体分层式 | 政策性强、责任主体明确的选题 | 政府 / 行业部门 / 企业 / 社区 / 个人（或按当事人主体分列），每主体 2–4 条 |
| 方式 B｜策略主题式 | 消费行为、营销类选题 | 破圈/精准营销/产品/渠道等策略主题，每条行动导向 |

- 常见替代结构：单产品建议 + 产业建议双层；阶段化建议（激活/创收/留存）；SWOT → 策略

## 三、映射模板

```
结论编号 → 证据（图表/检验/p 值）→ 建议编号 → 主体 → 动作 → 落地路径 → 预期效果
```

## 四、评审关注

- 结论是否回应选题提出的问题；
- 结论与数据之间的关联是否成立；
- 建议是否"切实可行、具有可操作性"（评审原文）。
