# 🧑‍🎓 E04_格远数智赋能

> 📌 选题档案：40 题，对应 格远数智赋能 第 17 届企业命题原文（`references/第十七届赛制资料/附加1：企业命题.xlsx`）。
> 每个选题目录内含 `选题说明.pdf` 与 `_topic.txt` 速览；DOCX 和水印 PDF 不在本目录保留。

## 一、命题要求摘要

格远数智赋能命题为“青年发展主题调查”，下设青年心理健康、青年就业创业、青年人工智能应用与数字素养三个子选题，要求衔接“十五五”规划支持青年发展专节、国发〔2025〕11 号“人工智能+”行动与国卫医政发〔2026〕8 号社会心理服务体系方案，按“本地前期研究—全国统一采集—数据深化应用”三阶段推进。

- 子选题①青年心理健康：压力新表现、服务可及性与使用成效、供需适配判断。
- 子选题②青年就业创业：灵活就业与慢就业新形态、支持政策落地成效、青年获得感。
- 子选题③青年 AI 应用与数字素养：素养水平测度、能力结构短板、提升支持体系适配。
- 数据口径：优先参与“全国一张卷”统一问卷，保证跨省可比；可先做本省基线预调研。
- 成果导向：形成可报送团中央及省市有关单位的调研报告与分项判断。
