# 2027 年企业命题选题生成规范（BRIEF）

## 一、任务背景

正大杯第 17 届市调大赛企业命题赛共 8 家企业（益普索、问卷网、同方知网、格远数智赋能、汇辽集团、酷冷保温、神启数据、中健国康）。现要在 `2027年企业命题/` 下为每家企业产出约 40 个**可直接参赛**的选题，每题须严格贴合该企业命题原文的要求（产品、场景、人群、地域、关注渠道），并与仓库既有 2000 题题库（`正大杯最新选题/`，21 个行业）风格一致：**一个题目包含两个研究点**，五段式档案（选题定位 / 生成假设 / 选题依据 / 可行性提示 / 参考来源）。

## 二、标题公式（硬性）

```
“主标题”——副标题
```

- **主标题**：中文引号内，≤16 字，口语化 slogan 或对仗短语，可含逗号，例如“腕上智能，青春首选”“冷库门后，谁在决策”。
- **副标题**：15～35 字，**必须同时包含两个可检验的研究点**，用“与”“及”“和”连接，以“研究/调查/测度/评估”收尾。两个研究点一般组合为：
  - 〔现状/需求/认知/画像〕 + 〔意愿/满意度/影响因素/转化/溢价接受度〕
  - 〔群体 A 视角〕 + 〔群体 B 视角〕（如采购方 vs 使用方）
- 禁止单研究点标题；禁止“某某购买意愿研究”这类无场景、无对象的泛题；禁止把企业名当主语写成广告语（如“酷冷保温引领行业”）。
- 副标题中不得出现“研究研究”“调查调查”等重复词；不得超长堆砌定语。

## 三、JSON 字段（严格按此 schema，字段名不可改）

```json
{
  "id": "E01-01",
  "title_main": "腕上智能，青春首选",
  "title_sub": "大学生智能手表购买决策要素与品牌态度研究",
  "full_title": "“腕上智能，青春首选”——大学生智能手表购买决策要素与品牌态度研究",
  "company_bucket": "产品创新与品牌定位",
  "industry": "03_人工智能与数字科技",
  "project_type": "消费者洞察",
  "stage": "early-mid（萌芽—成长期：需求与机会挖掘 + 意愿初探）",
  "region": "北京、上海、武汉",
  "object": "18–28 岁在校大学生及毕业 3 年内青年白领",
  "variables": "智能手表知晓渠道、佩戴时长、核心功能使用强度、购买考虑要素、品牌态度、换机意愿、支付溢价上限",
  "h1": "功能使用强度与换机意愿正相关，且受品牌态度中介（待验证）",
  "h2": "购买考虑要素在“性价比型”与“生态型”学生群体间存在显著差异（待验证）",
  "basis": "🔶IDC 中国可穿戴设备季度跟踪报告（2026）；✅《关于促进消费扩容提质的相关政策》；🔶小红书/抖音智能手表相关笔记与话题热度（须下载核验）",
  "feasibility": "北京/上海/武汉三城高校分层抽样，线上问卷 600 份 + 20 人深访；校园社群与电商评论区双渠道招募；难点为低年级样本代表性，用配额抽样校正",
  "sources": "IDC《中国可穿戴设备市场季度跟踪报告》；品牌官方商城与京东/天猫商品页；高校校园媒体",
  "fit_note": "直接回应命题第 1 项“大学生智能手表购买过程、使用习惯、品牌态度与营销方案设计”"
}
```

字段要求：

| 字段 | 要求 |
|---|---|
| `id` | 由调用方给定的编号规则，严格照填 |
| `company_bucket` | 该题对应的命题子方向名称（用企业原文的表述，如“爆款研究”“青年心理健康”） |
| `industry` | 必须取自下方 21 个行业全名之一 |
| `project_type` | 社会调查 / 企业与行业调研 / 消费者洞察 / 政策评估调研 四选一 |
| `stage` | `early` / `early-mid` / `mid` / `mid-late` 之一 + 括号解释（不超过 40 字） |
| `region` | 按企业规定的地域范围具体化到省市 |
| `object` | 具体人群/组织 + 限定条件，禁止“消费者”“企业”这类空泛表述 |
| `variables` | ≥5 个可测量变量，中文逗号分隔，不得含“等等” |
| `h1`/`h2` | 两条可检验假设，含关系或差异表述，句末加“（待验证）” |
| `basis` | 3–5 条证据线索，用“；”分隔，每条 ≤30 字，前缀 ✅（官方/权威可直接引用）或 🔶（行业报告/媒体线索，须核验）；须与命题产品的真实政策/行业语境相符 |
| `feasibility` | 抽样框、抽样方法、样本量、执行难点与对策，≤110 字 |
| `sources` | 与 basis 对应的来源名称（机构+报告名），用“；”分隔 |
| `fit_note` | 一句话说明如何回应企业命题原文（≤50 字） |

## 五、质量红线

1. **两研究点必须都能落地测量**：每个研究点都要能在 variables 中找到对应变量，问卷/访谈能问出来。
2. **40 题内部不得撞车**：同一企业内任意两题的“对象+变量组合”不得重复；同一命题方向下的题应从不同人群、不同场景、不同决策环节切分（如采购方/使用方/施工方/设计方/运维方）。
3. **跨企业也不得撞车**：8 家企业主题差异明显（益普索快消与媒介、问卷网研究工具、知网宏观测度、格远青年发展、汇辽装配式建筑、酷冷冷链围护、神启中小微 B 端、中健国康睡眠与电商），不得互相串题。
4. **避开近三年获奖红海**：老年人数字鸿沟、AI 换脸诈骗、直播围猎银发族、预制菜进校园争议等已被大量使用，若命题必须涉及，须换独特切口（如从采购决策链、验收标准、成本传导切入）。
5. **证据要真**：basis 中的政策文件名、报告名必须真实存在或明确标注为行业线索；不得编造具体数字（如“市场规模达 372 亿元”）；宁可用“据行业报告，规模持续增长”这类可核验的定性表述。
6. **语言**：简体中文，书面但不官腔；不使用“赋能”“抓手”“闭环”等空话堆砌；每条表述都要能对应到一个可执行动作。
7. **地域合规**：严格落在企业给定的省市范围内；命题写“全国”的可具体到 3–6 个代表省市。

## 六、交付方式

- 输出**纯 JSON 数组**（不要 Markdown 代码块、不要注释），UTF-8 无 BOM，写入指定文件（如 `_gen/E01.json`）。
- 每题一个对象，字段齐全且顺序如上；40 个对象。
- 写完后自检：JSON 可解析、对象数正确、id 连续、full_title 与 title_main/title_sub 拼接一致（`“主标题”——副标题`）。
- 最终回复只写：文件路径、对象数量、覆盖的命题子方向清单（每项一行），不要粘贴 JSON 全文。
